Right-shifting was a finding about 1a, not about this table

Last round C came in at 61 pt and I called it the answer. That held because 1a pulled its value column 60 pt in from the edge, so moving the table right closed a gap that was partly artificial.

On the original, values right-align to the column edge whichever side the table sits on, so C lands at 135 — no better than B and worse than E. The general claim was wrong. What survives is narrower: where the label starts matters more than how wide the table is, which is why every split here beats the reference and why the two-column split beats them all.

Why F is the pick

It is the only option that changes nothing you liked. Four rows, real labels, full width, values hard right — all intact. The rule stops sitting under the row and runs across it instead, from the end of the label to the value.

The distance is still 267 pt. That is the point: an index leader does not shorten the trip, it removes the cost of making it, because the eye tracks a line instead of jumping a void. If the gap still reads as too far with a leader in it, then the problem was the width after all and E is the answer.

Measured, worst case

Reference 267 · F 267 (led) · A 141 · B 125 · C 135 · G 135 · D 157 · E 94.

Worst case, not average: the widest gap in the block, always the row with the shortest label. KIT against a right-aligned value is what sets it in most of these.

E is the shortest header too

Two columns of two rows lands the first exercise at 155 pt against the reference's 215. It is both the shortest travel and the most list, which is a strong combination for something that invents nothing new.

What it costs is a single reading order. Four rows down a column is one path; a 2×2 is two, and nothing on the screen says which to take first.

B is the quiet contender

Lifting the kit out is the only change that fixes a second problem at the same time: the kit is the one row whose value length actually varies, so it is the row that will truncate first as a routine's equipment grows.

It also leaves three rows of near-equal label length, which is what makes its 125 respectable without any typographic help.

Unchanged underneath

Names wrap, the node centres on the first line, the ledger prints target beside prev with no delta, the columns pin, Start plays the ignition. The header itself pins nothing in any of these, so these rows scroll away with the title.
