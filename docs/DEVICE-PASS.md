# Device-pass queue

What has landed on main and is **awaiting Dave's device pass** — the
validation CI cannot do. Gesture layers, haptics, wrist behaviour, motion
feel, Dynamic Type reflow and anything that dispatches through hit testing
are invisible to XCUITest (see `.claude/rules/testing.md`), so a green suite
proves nothing about the ⚠️ riders below.

**Read this before touching a surface named here** — an item's ⚠️ rider is
often the reason the current shape is what it is, and the reasoning behind
every entry is in `docs/DECISIONS.md` under its dated entry.

**Format is one item per line, newest first.** That is load-bearing, not
cosmetic: git merges line by line, so a section written as one growing
paragraph makes every concurrent branch conflict. Never grow a line; add one.

**Delete an item once Dave has passed it on device.** This file is the queue,
not the record — the record is docs/DECISIONS.md, which is append-only and
keeps everything.
