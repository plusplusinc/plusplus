Which lever is worth pulling

Bars show how far each lever can realistically travel, not where it sits now. Commission rate — the number every affiliate roundup ranks by — moves the least.

Reading this honestly: the footer-only scenario needs roughly 22 million actives, which is a refutation rather than a target. The model only becomes arguable when the recommendation lands on a four-figure basket, attribution runs on a discount code instead of a cookie, and commission comes from a direct deal.

Affiliate is a margin business. At 100,000 actives it earns roughly what a subscription does only in the optimistic case, and it can be halved overnight by a third party — Amazon did exactly that across categories in April 2020. The two revenue lines don't compete for the same user, which is the real argument for running both.
